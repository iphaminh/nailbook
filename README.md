# NailBook

**Online booking for nail salons.** Clients book from a link or QR code, any
hour; no double-booking; no app to install; the salon gets a text for every
booking; loyalty points; clients can attach the design they want.

This repository holds NailBook's **landing page and product notes**. The booking
engine itself runs live at Dream Nails & Spa as part of the salon platform in
**[naildesk](https://github.com/iphaminh/naildesk)**.
